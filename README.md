# MessWatch 🍽️

AI-powered food-waste tracking and analysis for hostel mess management.

## Problem

Hostel mess kitchens often over-cook because daily demand is difficult to estimate, creating avoidable food waste and cost.

## Solution

MessWatch records cooked and leftover quantities, calculates waste percentages, and analyzes historical patterns to generate practical recommendations.

## ✨ Features

- Daily food-waste logging
- Cooked vs leftover tracking
- Automatic waste percentage calculation
- Pattern-based recommendations
- Dashboard for monitoring waste trends

## 🛠️ Tech Stack

- React + Vite
- Node.js + Express
- Axios
- JavaScript

## 🚀 Run Locally

### Frontend
```bash
cd client
npm install
npm run dev
```

### Backend
```bash
cd server
npm install
node index.js
```
